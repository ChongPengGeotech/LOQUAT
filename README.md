## LOQUAT
GPU-accelerated SPH solver for geotechnics

###REQUIREMENTS###<br />
NVIDIA CUDA Toolkit<br />
CMAKE<br />
Ubuntu / CentOS / Windows<br />

###COMPILATION###<br />
Under Linux: Use the following commands
```
mkdir build
cd build
cmake ..
make
```
Under Windows: Use CMake to generate Visual Studio solutions.

###RUN SIMULATION###
```
./LOQUAT /path/of/input/file/name_of_project
```
